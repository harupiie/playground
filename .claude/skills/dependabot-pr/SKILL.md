---
name: dependabot-pr
description: Dependabot の特定 PR を詳細調査し、対応方針を提案する
argument-hint: "<PR番号>"
---

`pnpm debug:dependabot-pr $ARGUMENTS` を実行して PR の詳細情報を取得し、以下を行ってください。

**調査項目：**

1. **バンプ内容の確認** — メジャー / マイナー / パッチの種別と、変更されたバージョン番号
2. **リリースノートの調査** — PR 本文中のリリースノート・チェンジログへのリンクを参照し、破壊的変更・非推奨 API・動作変更の有無を確認する
3. **diff の精査** — 実際の変更内容を確認し、依存関係のネスト構造や意図しない追加がないかを確認する
4. **利用箇所の影響範囲** — プロジェクト内の利用箇所から、変更が影響するコードパスを特定する
5. **脆弱性との照合** — `pnpm audit` の結果と突き合わせ、このPRが脆弱性や deprecation を解消するかを確認する

**上記をもとに、以下を提示してください：**

- **判定**: ✅ マージ可 / ⚠️ 要確認 / ❌ 保留
- **理由**: 判定の根拠を簡潔に
- **対応手順**: マージ前後に必要なアクション（テスト実行・設定変更・コード修正など）があれば具体的に列挙する
